# 🎲 Dice Game

## 🔗 Live Demo
[View Project](https://dice-game-paresh.netlify.app/)

Dice Game is a simple two-player game built using HTML, CSS, and JavaScript. It randomly rolls dice for both players and automatically displays the winner or a draw.

The project uses JavaScript for random number generation, DOM manipulation, dynamic dice images, and conditional logic.

This project demonstrates core JavaScript fundamentals through a simple and interactive web game.
